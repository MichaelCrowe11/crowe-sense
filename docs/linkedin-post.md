I spent the summer building the software for a sensor I do not have yet.

Crowe Sense is a node for a growing room: a Raspberry Pi 5, four Sensirion and Bosch
sensors under a louvered radiation shield, a 3D-printed housing, about $280 in parts.
It reads CO2, temperature, humidity, light and VOCs, keeps every reading on the node,
and pushes signed batches to a relay so the same numbers show up in the desktop app,
the web app, the phone, Cortex and the terminal. One contract, six surfaces, and the
readings get judged against 43 condition bands pulled from 68 of my own cultivation
videos, each band cited to the clip it came from.

Here is the part I want to say plainly. In June I published a dataset from an earlier
rig and described it as measured. In August my own provenance test showed the tent
channels were not sensor data, and I corrected the record. That test now gates every
dataset this company will publish. The software has run end to end for 23 days. The
sensors have not been in a room. That is the gap the next few months close.

Twenty years growing mushrooms, ten of them commercially, and about 195,000 of you have
watched me do it. If you run rooms and want a node in one of them, or you fund hardware
at this stage, my inbox is open.
